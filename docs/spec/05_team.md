# 05 チーム構成

## 規模
5〜10名

## スキル構成

| 背景 | 人数 | 備考 |
|------|------|------|
| Webフロントエンド（React等）初学者 | 約5名 | メイン層 |
| React Native 初学者 | 1名 | モバイル未経験 |
| Flutter 経験者 | 1名 | モバイル開発経験あり |

## 開発環境
- macOS / Windows（WSL）混在
- Node.jsバージョンは `.node-version` で統一
- エディタはVSCode推奨

## 方針
- 初学者が多いため、技術選定は学習コストを重視
- コードレビューで知識共有を促進
- READMEのセットアップ手順は初学者でも迷わないよう詳細に記載
